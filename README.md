📱 MySignupPage
MySignupPage is a simple Android app built using Java and XML in Android Studio, designed to demonstrate a basic signup form UI with Material Design elements.

🚀 Features
Beautiful signup screen with custom background

Input fields for:

Username

Email

Password

Re-enter Password

Vector icons for each input

"Register" button with Toast feedback

Social media icons (Google, Facebook, Twitter) at the bottom

Material Design styling using MaterialButton
